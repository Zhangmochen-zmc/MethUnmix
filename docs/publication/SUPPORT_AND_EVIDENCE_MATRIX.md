# Public support and evidence matrix — draft

Status: `DRAFT; report engineering and evidence scope only`.  A descriptor,
plan, or successful installation receipt is not an accuracy or scientific
claim.  Historical real executions remain bound to their own installed
software identities.

| Tool/output semantics | Input/route boundary | Reference/runtime | Asset installation | Engineering evidence | Scientific-evidence statement | Known limit |

assets.  No static count of CPU/GPU profiles is evidence of GPU validation.

descriptive/report-only.
